# Сервис учёта рабочего времени

Веб-приложение для фиксации рабочего времени по клиентам и задачам. Работает на телефоне и компьютере (PWA), данные хранятся в облаке (Render).

## Запуск локально
```
npm install
npm start
```
Откройте http://localhost:3000

## Деплой на Render
1. Создайте аккаунт на https://render.com (бесплатно, по почте).
2. "New" → "Web Service" → подключите этот git-репозиторий (или "Blueprints").
3. Render сам определит Node и запустит `npm start`. Версия Node задана в `.node-version` (24).
4. Получите ссылку вида `https://<app>.onrender.com` — открывайте её на телефоне и ПК.
5. На телефоне: "Поделиться" → "На экран «Домой»", чтобы установить как приложение.

## Важно про данные
База данных — файл `data.db` (SQLite) на диске сервера. На бесплатном тарифе Render диск **переживает перезапуски, но может быть очищен при пересоздании сервиса**. Регулярно выгружайте отчёт в CSV (кнопка в разделе «Отчёт»), чтобы не потерять данные.

## API
- `GET /api/active` — активные (незакрытые) записи
- `POST /api/entries` — создать запись (можно несколько параллельных активных)
- `POST /api/entries/:id/close` — завершить запись
- `PATCH /api/entries/:id` — обновить (клиент/задача/статус)
- `DELETE /api/entries/:id` — удалить
- `GET /api/entries?day=YYYY-MM-DD` — записи за день
- `GET /api/report?from=YYYY-MM-DD&to=YYYY-MM-DD` — отчёт по клиентам/задачам
- `GET/POST /api/templates`, `DELETE /api/templates/:id` — шаблоны задач
- `GET /api/clients`, `GET /api/tasks` — автодополнение
