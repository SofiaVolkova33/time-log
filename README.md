# Сервис учёта рабочего времени

Веб-приложение для фиксации рабочего времени по клиентам и задачам, с заметками, сроками и задачами-делами. Работает на телефоне и компьютере (PWA), данные в облаке (Render).

## Возможности
- **Звонок / Начать задачу** — фиксация времени по клиенту и задаче, поле заметок, срок.
- **Звонок**: выбор клиента (список последних + поиск). При звонке активные задачи переходят в режим ожидания; при завершении звонка — возвращаются прежние статусы.
- **Параллельные задачи**: несколько активных записей одновременно, переключение «В ожидании / Активно».
- **Задачи-дела**: отдельный todo-список по клиентам со сроком и заметками. Задачу можно «начать» — она попадёт в учёт времени, «завершить» — станет выполненной.
- **Заметки** редактируются прямо на карточке.
- **Отчёт** по клиентам и задачам за день/неделю/месяц, выгрузка в CSV.

## Запуск локально
```
npm install
npm start
```
Откройте http://localhost:3000

## Деплой на Render
1. Аккаунт на https://render.com (бесплатно).
2. "New" → "Blueprint" → подключите репозиторий (используется `render.yaml`).
3. "Manual Deploy" → "Deploy latest commit" при каждом обновлении кода.
4. Ссылка вида `https://<app>.onrender.com`. На телефоне — "Поделиться" → "На экран «Домой»".

## Важно про данные
База — файл `data.db` (SQLite) на диске сервера. На бесплатном тарифе Render диск переживает перезапуски, но может очиститься при пересоздании сервиса. Регулярно выгружайте отчёт в CSV.

## API
- `GET /api/current` — лента незавершённых (новые, в работе, в ожидании)
- `POST /api/entries` — создать (звонок/задача/дело; звонок переводит активные в ожидание)
- `POST /api/entries/:id/start` — начать задачу-дело
- `POST /api/entries/:id/close` — завершить (звонок возвращает прежние статусы)
- `PATCH /api/entries/:id` — обновить (заметки, срок, статус, текст)
- `DELETE /api/entries/:id` — удалить
- `GET /api/entries?day=YYYY-MM-DD` — записи за день
- `GET /api/todos` — задачи-дела
- `GET /api/clients`, `GET /api/tasks` — автодополнение
- `GET /api/report?from=&to=` — отчёт
